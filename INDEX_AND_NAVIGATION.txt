2. lead_scoring_model_training.py (PART 2)
   ────────────────────────────────────────
   What it does:
     ✓ Applies 6 different feature selection methods:
       - F-Test (statistical significance)
       - Mutual Information (non-linear relationships)
       - Random Forest (model-based)
       - Recursive Feature Elimination
       - L1 Regularization (LASSO)
       - Sequential Forward Selection
     ✓ Finds consensus features (selected by 3+ methods)
     ✓ Compares different feature sets
     ✓ Trains 3 models:
       - Logistic Regression (interpretable)
       - Gradient Boosting (balanced)
       - XGBoost (high accuracy)
     ✓ Performs hyperparameter tuning
     ✓ Uses cross-validation
     ✓ Compares model performance
     ✓ Selects best model
   
   Run it with:
     python lead_scoring_model_training.py
   
   Duration: 5-10 minutes
   
   Outputs generated:
     ├─ /home/claude/lead_scoring_outputs/
     │  ├─ 03_feature_selection_consensus.png
     │  ├─ 04_feature_set_comparison.png
     │  ├─ 05_model_comparison.png
     │  ├─ best_model.pkl (production model!)
     │  ├─ lr_model.pkl
     │  ├─ gb_model.pkl
     │  ├─ xgb_model.pkl
     │  ├─ optimal_features.csv
     │  └─ feature_importance.csv (YOUR WEIGHTS!)
     └─ These are used by the next script

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   ──────────────────────────────────
   What it does:
     ✓ Evaluates model on test set
     ✓ Generates ROC and PR curves
     ✓ Creates confusion matrix
     ✓ Analyzes calibration
     ✓ Shows feature importance/weights
     ✓ Generates lead scores (0-100)
     ✓ Creates business segments (Hot/Warm/Lukewarm/Cold)
     ✓ Performs lift analysis (expected uplift)
     ✓ Provides business recommendations
     ✓ Generates summary reports
   
   Run it with:

❓ COMMON QUESTIONS
═════════════════════════════════════════════════════════════════════════════

Q: Where do I see the "weights" of engagement metrics?
A: feature_importance.csv or 08_feature_importance.png
   Higher number = more important signal

Q: What's my model performance?
A: Check 06_evaluation_curves.png
   Look for AUC score > 0.70 (good) or > 0.75 (very good)

Q: How do I use this to score new leads?
A: See: lead_scoring_evaluation.py (Section 5)
   Or: comprehensive_methodology_guide.py (Section 6)
   Load best_model.pkl and call predict_proba()

Q: What if my AUC is low?
A: See: comprehensive_methodology_guide.py (Troubleshooting)
   Or: lead_scoring_execution_guide.py (Troubleshooting)

Q: How often should I retrain?
A: Monthly for monitoring, Quarterly for retraining
   See: comprehensive_methodology_guide.py (Section 4)

Q: What data do I need?
A: See: lead_scoring_execution_guide.py (Section 2)
   Minimum: email data + target variable
   Ideal: email + website + webinar + CRM data

Q: How do I modify the code for my data?
A: See: lead_scoring_execution_guide.py (Section 2)
   Change data loading line, keep rest the same
